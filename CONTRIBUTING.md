# How to upload your project

This guide explains how to add your files to this repository using only the GitHub website. You do not need to use the command line.

## Before you start

1. Create a free account on [github.com](https://github.com) if you don't have one.
2. Send your GitHub username to Jose Chavarria over slack or email, so you can be added as a collaborator.
3. Accept the invitation you will receive by email.

## Uploading files

1. Open the repository and click on your project folder (for example `Curio`).
2. Click on the subfolder where your files belong (`code`, `schematics`, `images` or `presentation`).
3. Click **Add file** and then **Upload files**.
4. Drag your files into the page. You can drag a whole folder too.
5. At the bottom, write a short message describing what you added, for example `Add final Arduino sketch`.
6. Click **Commit changes**.

## Editing your project README

1. Open `README.md` inside your project folder.
2. Click the pencil icon (Edit this file).
3. Complete the parts marked with comments like `<!-- Team: ... -->`, and the *How to build it* section.
4. Use the **Preview** tab to see how it will look.
5. Click **Commit changes**.

To show your cover image at the top of the README, upload a picture named `cover.jpg` to your `images` folder.

## Important rules

- **Never upload API keys, passwords or Wi-Fi credentials.** All the projects use AI services, so check your code carefully before uploading. If you uploaded a key by mistake, tell your teacher and **revoke the key right away** in the service's dashboard (deleting the file is not enough, because GitHub keeps the history).
- Single files must be smaller than 100 MB. Put long videos on Vimeo or YouTube and link them in the README.
- Only work inside your own project folder.
- Use descriptive file names without spaces, for example `wiring-diagram.png` instead of `Screenshot 2026-03-20 at 14.32.png`.
