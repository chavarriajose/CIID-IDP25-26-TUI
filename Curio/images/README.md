# Images

Project: **Curio**

Put photos and videos of the project here: the final prototype, earlier prototypes, process pictures, people using it.

Tips:

- Use `.jpg` or `.png`, and try to keep each image under 5 MB.
- Give files descriptive names, for example `final-prototype-front.jpg` instead of `IMG_4032.jpg`.
- For videos, it is better to upload them to Vimeo or YouTube and add the link to the project README. GitHub does not accept files bigger than 100 MB.
- Only upload pictures of people who agreed to be shown.
