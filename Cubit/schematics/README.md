# Schematics

Project: **Cubit**

Put here everything someone needs to rebuild the electronics and the physical object.

For example:

- Wiring diagrams (Fritzing `.fzz`, KiCad files, or a clear photo or drawing exported as `.png` / `.pdf`)
- Bill of materials (a list of all components)
- Files for fabrication: 3D models (`.stl`, `.step`, `.f3d`), laser cutting files (`.svg`, `.dxf`, `.ai`)

Tip: always add a `.png` or `.pdf` version of each schematic so people can see it directly on GitHub without installing any software.
