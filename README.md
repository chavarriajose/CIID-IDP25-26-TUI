# Tangible User Interfaces 2025/26

Open source projects from the **Tangible User Interfaces** course of the [Interaction Design Programme](https://www.ciid.dk/idp-courses/tangible-user-interface-2025-26) at the **Copenhagen Institute of Interaction Design (CIID)**, February 2026.

## About the course

Large language models can do remarkable things, but most of the time we talk to them through a chat box. In this hands on course, students designed and built physical objects that talk to an LLM through an API, exploring how touch, movement, light and sound can create more meaningful ways of interacting with AI than a text field on a screen.

Each team started from a familiar app experience and turned it into a tangible artifact, prototyped with Arduino.

**Faculty:** Jose Chavarria and Massimo Banzi

## Projects

| Project | Description | Team |
|---|---|---|
| [Sketch Tales](SketchTales/) | A bedside storytelling lamp that turns a child's drawing into a narrated bedtime story. | Prianka Kaur, Naman Jain, Nikhil Sajjan, Hitesh Kukreja |
| [Auracle](Auracle/) | A music device that uses oracle cards to choose your song of the day. | Diana Chaves, Haley Rowland, Cassandra Quesada |
| [Curio](Curio/) | A handheld device with magnetic lenses that helps children explore the world with AI. | Davide Airoldi, Pedro Josué Matarrita Brenes, Andrés Gómez, Kabir Shrivastava |
| [Cubit](Cubit/) | Two cubes you rotate to mix a mood and a genre, and discover new music. | Ella Park, Maryam Safai Fard, Daniela Gómez |

Each project folder has the same structure:

```
ProjectName/
├── README.md        Description, team, how it works, how to build it
├── code/            Source code
├── schematics/      Wiring diagrams, bill of materials, fabrication files
├── images/          Photos and process pictures
└── presentation/    Final presentation (PDF)
```
